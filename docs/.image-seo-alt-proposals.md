## 3. Purely Decorative Images (Intentionally Kept Empty / Aria-Hidden)

### Component: StickyBookingBar (Mobile/Desktop Floating Brand Icon)
- **file / component / page or route**: `src/components/StickyBookingBar.tsx`
- **image src**: `/logohemnha/logohem-9.png`
- **old alt**: `""`
- **new alt**: `""` (remains empty with `aria-hidden="true"`)
- **decision note**: This 28px icon is rendered directly adjacent to the visible brand label `{t.stickyBar.brand}` ("Hẻm Nhà Living") inside a floating CTA pill. Adding alt text would cause screen readers to announce redundant text ("Hẻm Nhà Living Hẻm Nhà Living"). It is purely decorative context for the adjacent text label.
